Nuvio Discover - Sharp Hero Backdrop Replacements

These are replacement hero backdrops for the five Discover folders.
Each image is 2560 x 1440 WebP.

They are generated from the approved category cover artwork, enlarged with
high-quality resampling, gently darkened for UI readability, and sharpened.
No Gaussian blur is applied.

Copy each category's Backdrop/backdrop.webp into:
D:\GitHub\nuvio-artwork\Discover\<Category>\Backdrop\backdrop.webp

The installer script supplied separately backs up existing backdrop.webp
files before replacing them.
